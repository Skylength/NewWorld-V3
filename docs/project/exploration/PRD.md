# 动态区域探索与调试控制台

更新：2026-10-15。状态：用户已明确要求设计并实现本功能，并指定“文本输出用 sol，判断或结构用 luna”的默认路由。双阶段路由和图形化链路控制台已实现并完成自动验证，待用户试玩验收。实际证据见 [测试报告](TEST_REPORT.md)。

## 目的

玩家用自然语言探索世界，未预设的地点能够在游玩中生成，同一地点随观察和行动逐渐丰富，离开后返回仍保留已发生的变化。提供本地网页试玩与可视化调试控制台，帮助用户检查世界如何生成、上下文如何装卸。

## 本次范围

- 从少量宗门背景开始，不预先制作南疆、地牢等目的地。
- 支持自由输入、移动、观察、调查和开放行动。结构模型结合已保存事实判断行动并提出区域与状态更新，文本模型依据通过校验的结果生成玩家叙述。
- 地点具有稳定身份和可选上级地点；当前区域沿上级链加载，另行展示因输入相关而加载的资料。
- 已知地点重复访问复用原记录；补充细节与状态变化分别保存并提供前后差异。
- 自动保存，可刷新、重启后继续；支持创建新的独立试玩存档，已有存档保留。
- 控制台展示区域结构、当前地点、区域详情与状态、历史回合、实际请求提示词、原始模型输出、提交差异、耗时、请求数与 token 用量、失败和取消。结构与文本阶段分别可查，旧的单阶段请求历史保持可读。
- 试玩与调试工作台独立切换。试玩保留叙述和行动输入；调试以“找到异常 → 定位环节 → 核对证据 → 确认世界后果”为主线，作为后续持续使用的工作工具。
- 左侧运行列表支持搜索、状态筛选、固定历史记录和跟随最新。中央以可点击链路呈现“输入与背景 → 结构判断 → 结构校验 → 文本叙述 → 提交世界”，右侧检查器随节点展示证据；原始提示词、JSON 和完整 ID 按需展开。历史排查时新轮询不能抢走选择或关闭已展开证据。
- 模型调用用真实起止时间绘制等比例时间条；其余耗时明确为未拆分。上下文以字符组成图解释各模块占比和加载原因，结构请求、文本请求与当前下轮预览分别查看。模型报告 token 独立显示，未知用量不能当作零。
- 世界变化用位置迁移和区域分组对照展示，失败/取消的候选结果不能标为已提交。历史请求只使用当时记录的名字、状态和差异；“当前世界”单独展示最新区域层级、档案和装载情况。旧记录不补造未记录的阶段、耗时或校验结果。
- 桌面提供列表、图形工作区和证据检查器的稳定布局，窄屏顺序重排；正文保持可读，支持键盘操作、复制证据与导出所选运行。
- 沿用已有模型服务与凭据，默认结构判断使用 gpt-6-luna、玩家文本使用 gpt-6.1-sol；未配置时明确提示，不将脚本演示冒充真实生成。
- 每轮至多两次模型请求，无隐藏重试；两个阶段共同受整轮 120 秒时限约束。仅在结构和文本都成功后保存世界与叙述，任一失败或取消都保留原世界。

本功能验证区域探索闭环。场景中的背景人物可以随地点内容生成；现有独立 NPC 受控回应入口保持可用。本次不宣称已经接入完整独立 NPC 交往、战斗、经济或离屏自主模拟。用户角色的未表达选择和内心不由世界模型代写。

## 验收场景

1. 前往一个尚不存在的地区：创建地点并切换当前位置，抵达叙述与保存的地点一致。
2. 留在当地调查：保留原地点 ID，添加相关细节，不每轮重建场景。
3. 改变环境状态：例如标记墙面、开门，保存状态及原因。
4. 离开并返回：沿用原地点及已保存的变化，不恢复初始状态。
5. 查看控制台：从失败筛选进入请求并自动定位异常节点；点击链路查看证据，时间条正确反映实际调用；切换两阶段上下文并查看字符组成、装载原因及当前下轮预览；区分候选/已提交变化，历史不会被最新世界污染；固定记录不随轮询跳走，导出内容属于所选运行，旧记录和窄屏正常显示。
6. 刷新或重启：继续同一世界；结构或文本任一阶段取消或失败，都不会提交半轮世界变化。

工程检查负责引用、重复地点、层级环路、原子保存、取消、预算与协议；场景合理性与自由探索体验通过真实模型样本和用户试玩检查。自动通过不替代用户验收。
