# 世界与动态区域 PRD

## 2026-11-06：Director 初版与统一游玩（已实现，待用户验收）

用户已授权统筹设计、修改并迭代世界、区域和 NPC 系统。本次覆盖四项需求：玩家创建并实体化人物；自由行动生成与返访地图；NPC 主动交互；记忆随实际经历形成并正确检索。该授权覆盖具体实现选择，无需再次申请开发许可。用户体验验收另行记录。

- Director 是独立于 NPC 的世界创作 Agent，沿用结构路由和 Pi 执行。负责场景与人物初始创建、玩家行动的场景后果、可感知观察及交谈投递提案；独立 NPC 自己回应。
- 主输入支持与已启用 Agent 的在场人物交谈，不再要求切换人物面板。玩家原话或明确的说话意图进入人物经历，隐含想法、界外评价不自动广播。
- 人物面板提供直接创建入口，保存稳定身份、公开简介、私人性格和目标；创建与启用独立 Agent 分开，启用由玩家操作。
- 场景观察根据地点与实际在场分发；远处人物不读取玩家整轮叙述。已形成经历可在后续互动、离场与重启后回忆。
- 新地点应展开具体可接触内容，地图投影真实区域身份；返访保留原身份与变化。既有角色不随玩家自动移动。
- 生成、NPC 反应、叙述完成后统一提交。失败与取消不得留下半轮场景或虚构记忆；实际模型调用证据保留。

完成证据须分别覆盖人物创建/启用、自由生成/返访、没有直接催促的主动行为、经历检索/信息隔离/重启连续性。仅类型检查不代表以上体验完成。


## 2026-11-06：场景创作与自然推进修订

本节取代旧版“普通输入锁定位置”和固定探索模式的语义。玩家通过自然语言表达行动与对白；AI 提供世界内容、场景反应及合理后果。地图是快捷入口。区域创建不等于内容已充分展开，也不要求固定遵循入口、事件、选择的顺序。

- 推进尺度随玩家授权、环境和当前情节变化：概括普通过程，保留重要选择；对话可以直接回应，休息可以平静完成，不强制每轮生成冲突、人物、奖励或悬念。
- 开放探索应提供具体可理解、可接触的内容，不反复把全部内容放在“深处未知”。已充分展开的环境允许没有新发现。
- 新内容应延续已确认事实；行动的持久后果写入区域档案。玩家评价不直接成为世界事实。
- 角色自主决策、完整战斗、通用物品系统仍不在本次范围。提示词是生成约束，不是对全部开放输入的程序保证。

本次仅优化结构与叙述提示词，接口和存档结构保持不变；初始验证预算 4 轮、8 次请求；首组内容质量未达标后，明确追加修订版 2 轮，总上限 6 轮、12 次请求。实际结果单独记录，不挑选重跑样本。

## 本次授权增量：动态地图、明确迁移与提示词差异

用户已明确要求设计、开发并实现本增量。保留已有区域生成与双阶段提交，在试玩中接入“叙事为主”的动态地点地图；下文 v0.2 范围和历史证据继续作为基础。

- 地图来自当前存档的真实区域档案，生成并提交新区域后自动增加节点。连线只表达区域包含关系，不伪造道路、距离或通行能力；首版提供已知地点的明确区域切换。
- 点击地图上的非当前地点即发起迁移；显示目标和进度，成功后切换已保存位置并展示转场，失败或取消保持原位置。仅看详情不会迁移；当前地点不可重复发起。
- 普通“就地行动”在服务端锁定当前位置；“探索新区域”是显式输入模式，允许创建并进入新区域；地图迁移绑定已有目的地，模型不得改目的地或重建档案。独立押送等被动移动暂不作为普通就地行动的例外。
- 地图迁移的结构请求即装载目标及其上级的完整背景，并明确记录真实出发地。目标上下文是本轮候选转场依据，双阶段成功前不表示已经到达。
- 调试工作台增加“提示词差异”：分结构/文本阶段，默认对比上一条有实际请求的同阶段记录，也可选择更早记录；逐行呈现删除、增加、行号和上下文，支持复制差异。首次请求标明无历史基线；没有实际发出的请求不冒充已有请求。
- 差异基于当时保存的 system/user 原文，当前世界和后续轮询不得改写历史比较；失败请求可以参与比较，但必须显示其失败状态。

验收操作：实际生成新地区 → 地图出现节点 → 点击旧地点生成转场 → 核对该请求装载目标背景 → 在差异中检查区域提示词的删除/新增 → 刷新后位置和地图保留。另检查重复点击、失败/取消、就地行动不能迁移和历史差异固定。本增量不含背包、技能、完整道路或 NPC 自主模拟。

## 1. 目标与最小闭环

让玩家通过自然语言进入预设之外的地方、尝试预设之外的行动，并在再次访问时发现自己和世界的互动确实留下了后果。预设负责提供起点和共同前提，AI 根据探索需要补全尚未展开的部分，不要求先制作完整地图或所有玩法。

最小闭环：**提出行动 → 读取有关世界资料 → 按需生成或补全区域 → 落实实际结果并保存 → 根据新位置继续互动 → 离开后重返同一地点。**

本次围绕三类能力组织需求：世界档案、位置上下文装配、统一的世界生成与更新。未知感来自合理的新环境、人物和互动机会；安静的日常发现也有价值，不要求每次观察都产生宝物、阴谋或任务。

## 2. 核心概念

| 概念 | 产品含义 |
| --- | --- |
| 世界核心 | 每次互动都需要保持的简短共同前提，如题材和必要规则；不是完整世界百科。 |
| 世界资料 | 可以较详细的地域、人物和背景内容。首版由区域档案承载与本功能有关的部分，不承诺任意类型世界书的编辑和导入。 |
| 区域／地点 | 需要独立描述环境、记录变化或区分交互条件的空间。可以是南疆，也可以是宗门内的一座地牢，允许嵌套。 |
| 当前位置 | 玩家实际所在的地点。提到、回忆或打听某地不等于身在当地。 |
| 稳定描述与当前状态 | 稳定描述保留环境特征；当前状态记录门锁、标记等会变化的条件。新状态必须在后续互动中延续。 |
| 生成与发生 | 首次生成地牢资料，可以是首次展开原本存在的地点；在故事中修建一座地牢，则是需要经过行动和时间的事件。 |

是否建立独立区域由交互需要决定：移动到广场另一侧不必新建地点；进入环境和接触条件不同的地牢时可以建立子区域。地点生成后保留稳定身份，改称呼、继续调查或再次访问不能随意创建副本。

宗门身份与宗门位置分开：身在宗门时保留当地背景，离开后仍可作为宗门弟子行动。空间归属不自动等于组织归属，例如“某宗门在南疆经营的店铺”不必作为宗门驻地的空间子区域。

## 3. 行为要求

### W-01 世界与位置背景

- 世界最小核心保持有效；当前地点与必要的上级区域随位置装载。
- 身在“青云宗／地牢”时同时保留宗门背景和地牢现状；进入南疆后，宗门不再作为当前环境。
- 远处地点资料可以因询问或回忆而出现，但应与当前环境明确区分。离开只改变本次上下文，不删除地点档案、人物身份或过去经历。
- 背景载入与人物是否在场是不同问题。不能因为宗门资料包含某个人，就认定此人正在地牢中。

### W-02 未知区域的按需展开

- 玩家可以前往未预设的目的地，也可以探索已知区域内部尚未展开的空间。
- 先复用已存在的地点。新地方只展开当前互动所需的规模；前往南疆时可以建立南疆与一个具体落脚点，不要求同时生成所有城镇。
- 一般提及不强制创建完整地点。首版允许通过现有描述保留名称或线索，后续实际需要时再建立独立档案，不要求建设专门的“已提及地点”系统。
- 新地点需要符合世界前提和已经确认的线索；不能为了保证玩家成功或失败临时推翻旧事实。
- 抵达回复应使用本轮实际生成并保存的地点内容，下一轮继续使用同一地点。

### W-03 继续探索与可交互内容

- 玩家留在原地观察、调查、接触背景人物，可以逐步发现普通环境细节、用途、日常活动及可继续互动的线索。
- 尚未展开不等于什么都没有。不能反复用“没有记录”“没有特别之处”代替合理补全。
- 已经充分观察、暂时缺少观察条件或重复行动没有新结果时，可以没有新发现。不能每轮无条件增加区域和事件。
- 背景人物可以作为场景内容出现并延续已确认事实；是否具有独立目标、私人记忆和离屏行动能力，另按 NPC 功能验证。

### W-04 开放行动与世界更新

- 玩家可提出未预先列成按钮或命令的行动，例如刻下标记、寻找可利用的材料、尝试装病或试探出口。
- 行动愿望不自动等于成功。结果可成功、失败或部分达成，并根据已知条件解释后果；未知细节允许合理补全。
- 已成立的重要发现与持久变化需要保存。叙述说门已打开，后续应按打开的门继续；日志中的一句话不能代替当前状态。
- NPC／背景人物行为已经产生的区域后果，同样应进入持续状态。首版背景人物的叙述回应不构成“完整独立 NPC 已运行”的证据。
- 不代写玩家尚未表达的选择、台词和内心；遇到需要玩家作新选择的节点停下，不连续替玩家完成后续冒险。

### W-05 移动、快进与被动迁移

- 普通就地行动在程序中禁止改变位置；地图点击固定已有目的地，探索模式才允许模型依据明确探索输入决定目的地。“听说南疆”“回忆地牢”应使用就地行动。
- 快进可以概括旅程并累计世界时间。首版不承诺沿途每段路程、所有 NPC 行动或长期事件都已模拟。
- 后续被押入地牢的世界事件需要专门接入；当前不允许它绕过就地行动的位置锁。“战败 → 被俘 → 押送到达”不能仅凭玩家愿望或人物台词就全部成立。可以将已确认的关押处境作为探索场景的前提，但不据此宣称完整战斗或押送系统已实现。
- 无法确定旧地点指代时可以澄清并保留原位置，不能用新建一个近似地点绕过问题。

### W-06 返回、连续游玩与失败

- 离开后重返同一地点，保持身份、已确认的描述及最新变化。没有新事件原因时，不恢复初始状态。
- 自动保存后，刷新或重启继续原世界。关闭应用的现实时间不增加世界时间。
- 生成、验证或保存失败，或者用户在提交前取消，不产生半轮世界更新；玩家能辨认已提交与未提交的结果。
- 世界逐步增长超出当前能力范围时，要明确说明限制并保留可用存档，不能默默丢失重要事实或承诺无限容量。

### W-07 过程可检查

用户能查看本轮装载了哪些区域及原因、生成了什么、修改了什么，以及最终哪些内容实际保存。已有调试工作台的具体保留要求见第 7 节；排查工具不成为正常游玩的必经步骤。

## 4. 本轮设计边界

本功能先验证单玩家的世界探索与状态延续，不建设完整地图、精细寻路、战斗数值、经济与物品实体系统、复杂秘密传播或全世界离屏模拟。不新增专门的区域生成 Agent、记忆 Agent、导演 Agent 和自动语义裁判链。

已有独立 NPC 回应能力继续保留。未来接入时，NPC 根据自身可知信息决定意图，世界处理负责环境和实际后果；世界模型不能替独立 NPC 改写意愿。当前探索存档没有独立人物位置表、私人知识权限和唤醒队列，这些要求不算本功能已交付。

完整世界书编辑、任意剧本导入、地点重命名与重挂层级、自动长期压缩、玩家世界主人修改及重演入口，均不是这次整理自动新增的开发范围。先保留现有探索数据结构与运行方式。

## 5. 场景推演

### 宗门到南疆，再返回

| 玩家行为 | 预期结果 |
| --- | --- |
| 在青云宗山门询问南疆 | 可以提供或补全有关信息，仍位于山门。 |
| 明确前往南疆并快进 | 按需建立南疆与具体落脚点，保存实际抵达位置与耗时。 |
| 继续调查落脚点 | 复用原 ID，补全有据的细节，保留可继续互动的内容。 |
| 在普通木牌背面刻下记号 | 根据条件判断结果；如果成功，记号成为持续状态。 |
| 离开后回到先前落脚点 | 复用同一档案，记号仍在，除非期间已有明确改变它的事件。 |

### 动态地牢与开放行动

以“已经成立的关押处境”开始，地牢此前未生成。系统建立符合所在区域的地牢，保存铁门、环境和必要的背景人物；玩家随后尝试用现场材料装病。看守是否相信、是否开门保持开放，不能预定越狱成功。已经发生的门锁或环境变化保存，离开再返回仍然延续。首版检验世界补全和后果连续性；独立看守自主决策及认知隔离属于后续 NPC 接入验收。

| A-09 | 玩家控制 | 不代写玩家未表达的选择或内心，新的决策机会留给玩家。 |
| A-10 | 失败与取消 | 任一阶段失败或提交前取消，位置、区域和时间不发生半轮更新；失败可查看。 |

开放行为验收采用首次有效输出，保留失败和执行错误；不靠反复重生成挑选结果，不规定固定对白或必须成功。工程能检查的数据约束与人工审阅的合理性分别报告。用户验收仍独立于自动检查。

## 7. 现有试玩与调试能力的保留范围

以下承接 2026-10-15 已有实现和文档，保留原范围与证据；不会因这次按简化方案整理而重置为未开发，也不会视为本轮新增交付。

- 从少量宗门背景开始，不预先制作南疆、地牢等目的地。
- 支持自由输入、移动、观察、调查和开放行动。结构模型结合已保存事实判断行动并提出区域与状态更新，文本模型依据通过校验的结果生成玩家叙述。
- 地点具有稳定身份和可选上级地点；当前区域沿上级链加载，另行展示因输入相关而加载的资料。

### 已有试玩操作

1. 前往一个尚不存在的地区：创建地点并切换当前位置，抵达叙述与保存的地点一致。
2. 留在当地调查：保留原地点 ID，添加相关细节，不每轮重建场景。
3. 改变环境状态：例如标记墙面、开门，保存状态及原因。
4. 离开并返回：沿用原地点及已保存的变化，不恢复初始状态。
5. 查看控制台：从失败筛选进入请求并自动定位异常节点；点击链路查看证据，时间条正确反映实际调用；切换两阶段上下文并查看字符组成、装载原因及当前下轮预览；区分候选/已提交变化，历史不会被最新世界污染；固定记录不随轮询跳走，导出内容属于所选运行，旧记录和窄屏正常显示。
6. 刷新或重启：继续同一世界；结构或文本任一阶段取消或失败，都不会提交半轮世界变化。
