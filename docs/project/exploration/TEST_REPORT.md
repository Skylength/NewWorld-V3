### 初版边界

仍为本机JSON单写入者，最多100个人物、12个独立Agent；每段6次激活、每人2次，单决策2次请求。长等待可能暂停，选择继续或停止；世界关闭后暂停。中文检索为词片段相关性，没有向量库或长期记忆压缩。Director对行动意图、可感知内容和不代演人物的自然语言判断依赖模型；程序保证身份、位置投递与实际提交边界，并非对所有开放叙述的语义证明。跨多个地点、多个时刻的复杂指令需要分段游玩。
