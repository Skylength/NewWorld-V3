## 边界与用户验收

- 本次是区域探索切片，场景背景人物由世界生成；没有把原 NPC 受控回应入口扩充为完整独立角色、战斗或离屏模拟。
- 时间随本轮行动累计，关闭应用不推进；本版没有长期事件调度。
- 当前世界单进程串行运行，本地自动存档；不提供多人或多进程同写保证。
- 不调用长期摘要模型。完整请求最多 24000 字符，提交后的必要上下文最多 20000；超限会明确拒绝，当前世界保持原状。
- 最近 50 次请求保留完整调试记录，世界回合与区域状态持续保留；验收运行每步另写独立报告。
- 结构检查不能完全验证开放叙述与状态的语义一致性。用户重点观察是否合理补全、是否擅自改变意愿、是否在返访时延续变化。
