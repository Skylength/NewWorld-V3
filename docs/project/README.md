# 项目入口

更新：2026-10-15。NPC 主线为 **Stage 1：让 NPC 活起来**；当前交付动态区域探索切片。

NewWorld V3 以独立 NPC agent 和共同世界为基础，参考 V1、V2 与 Liyuan 的经验。后续按功能完成需求讨论、PRD、技术架构、方案确认、开发测试、测试报告、用户验收、学习和学习总结，具体规则见 [SOP](DEVELOPMENT_SOP.md)。

## 当前状态

- 动态区域探索与可视化调试控制台已实现：自然语言生成新地点、逐步丰富和保存变化、核对实际上下文。控制台现升级为独立工作区，重点展示阶段链路、真实调用耗时、上下文组成及世界差异。功能资料见 [PRD](exploration/PRD.md)、[技术架构](exploration/ARCHITECTURE.md)、[测试与试玩记录](exploration/TEST_REPORT.md)。真实样本及初始失败保留，待用户试玩验收。

- 六类 NPC 能力的总体方向已确认；Stage 1 技术架构 v0.1 已形成可审阅方案，尚待用户确认。
- 首个“接收观察 → 按需回忆 → 完整回应”能力已完成并获用户确认，测试证据与质量项保留。
- 独立 NPC 的完整世界动作、通信投递、新经历形成和后续唤醒尚未实现。其架构已给出状态、决策、提交、调度、持久化、预算和五步实施建议，尚未进入开发。
- 现有学习文档合并首个回应能力的既有资料，不代表整个 Stage 1 已验收或学习完成。
